# Spark (Email)

Spark is an email app by Readdle (macOS, Windows, iOS, Android). The FO uses it
for the finance inbox, **`finance@gss.ubc.ca`**.

## Why Spark

- **Fast sorting with keyboard shortcuts.** You can archive, move to a folder,
  snooze, or pin without touching the mouse, so clearing the inbox goes quickly.
  The full list is under Spark's settings (Shortcuts).
- **Reminders.** Snooze an email so it comes back to the inbox at a set time, or
  set a reminder that brings a thread back if nobody replies by a certain date.
  This is useful for invoices, signatures, and documents you're waiting on.
- **Scheduled send.** Write a reply now and choose when it goes out (Send
  Later). For example, you can keep late-night replies to business hours, or
  time a reminder to arrive the morning before a deadline.

---

## Working Practices

1. **Work through the inbox once or twice a day**, not continuously. Each email
   gets one of four outcomes: reply now, snooze or set a reminder, file to a
   folder, or archive.
2. **File anything that needs no further action** into its folder (see below),
   so the inbox only holds open items.
3. **Use reminders instead of leaving emails unread** as a to-do marker. For
   follow-ups that aren't tied to one email, use [FollowUpThen](../followupthen/).
4. **Use scheduled send** for anything that should land at a specific time.

## Folder Filing Taxonomy

{: .warning }
**Work in progress.** This folder list is still being refined and may not
match the current folders in the finance inbox. Update it here when folders
are added, renamed, or retired.

| If the email is about… | File to |
|------------------------|---------|
| Insurance, certificates of insurance, legal counsel, liability | **GSS Legal and Insurance** |
| Investments, HFC business, endowment, equipment leases | **House Finance Committee** |
| Audit, auditors, audit findings | **Audits** |
| Food Security Initiatives, Food Hub, Baby Hamper, food bank | **Food Security Initiatives** |
| Meal subsidy program and ticketing | **Meal Subsidy Program** |
| Hiring, job descriptions, salaries, payroll, staff HR | **HR Admin** |
| Building maintenance, repairs, facilities services | **GSS Facilities** |
| IT, systems, accounts, access | **GSS IT** |
| GSFA applications and financial aid disbursement | **GSFA** |
| Council, committees, governance, motions, minutes | **Council and Committee Meetings and Affairs** |
| AMS matters and re-affiliation | **AMS** |
| Board of Governors submissions, UBC administration meetings, G+PS | **UBC Admin Meetings** |
| Main lease, occupancy debt, rent repayment | **UBC-GSS Lease** |
| Commercial rent repayment (arrears) | **Commercial Rent Repayment** |
| Ballroom rentals and subtenants | **Ballroom Rental** |
| GST, taxes, CRA filings and refunds | **Taxes** |
| Vendor invoices, payables, bank / Plooto / Zoho admin, disbursements | **Finance Admin** |
| Calendar invites and event invitations | **Calendar Events** |
| General GSS or executive admin not covered above | **GSS Admin** |

**When unsure,** leave the email in the inbox rather than guess. Only file
emails that need no further action from you.

## Using Spark with Claude

Claude can read the finance inbox through Spark to summarize long threads,
build a timeline of what was agreed, and draft replies that open in Spark for
you to review and send. A daily triage routine also uses Spark to produce the
morning inbox digest. See [Claude](../claude/#reviewing-long-email-threads-in-spark).
